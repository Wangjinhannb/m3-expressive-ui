# Product Archetypes

Pick the closest archetype before styling. This prevents every product from becoming the same rounded dashboard.

## Dense productivity

Examples: mail, calendar, project management, admin, CRM.

Expression level: **Quiet**.

Use:

- Dense lists/grids.
- Tonal selected navigation.
- Large rounded search/create controls.
- Calm surfaces.
- Crisp iconography.
- Strong keyboard/focus behavior.

Avoid:

- Oversized cards for each row.
- Large colorful hero panels on every screen.

## Finance and trading

Examples: exchange, portfolio, payment, analytics.

Expression level: **Quiet to Balanced**.

Use:

- Large, clear numerals for price/balance.
- Dense tables where users compare many assets.
- Rounded filter/search/order-entry groups.
- Tonal container hierarchy.
- Blue/neutral primary action color.
- Red/green reserved for financial loss/gain or sell/buy semantics as the product defines them.
- Expressive motion only on order confirmation, onboarding, portfolio milestones, or major state transitions.

Avoid:

- Default black/neon "crypto" styling unless the user explicitly wants it.
- Decorative brand red/green that conflicts with market semantics.
- Converting every market row into giant cards.

## AI / assistant

Examples: chat assistant, generation tool, agent workspace.

Expression level: **Balanced to Expressive**.

Use:

- Large rounded prompt/search surface.
- Calm conversation canvas.
- Gradients to indicate thinking, synthesis, voice, or generation.
- Circular/rounded motifs.
- Responsive/morphing controls.
- Directional motion that explains process.

Avoid:

- Rainbow gradient on every message.
- Excessive glassmorphism.

## Consumer media / photos

Expression level: **Balanced to Expressive**.

Use:

- Let content dominate.
- Rounded media groupings where they improve scanning.
- Scrapbook/asymmetric composition for memories or curated moments.
- Minimal navigation chrome.

Avoid:

- UI decoration that competes with the media.

## Maps / canvas / creative tools

Expression level: **Quiet to Balanced**.

Use:

- Keep the map/canvas primary.
- Floating rounded controls and toolbars.
- Contextual sheets.
- Clear zoom and action hierarchy.

Avoid:

- Large opaque side panels that unnecessarily hide the canvas.

## Commerce

Expression level: **Balanced**.

Use:

- Tonal categories and filters.
- Strong product imagery.
- Clear price/CTA hierarchy.
- Rounded search and chips.
- Expressive moments for cart success, onboarding, and promotions.

## Developer tools

Expression level: **Quiet**.

Use:

- High information density.
- Monospace only where code/data needs it.
- Calm surfaces and strong keyboard focus.
- Rounded command/search surfaces.
- Selective shape/color on actions and status.

Avoid:

- Forcing consumer-level whitespace into code/data workflows.
